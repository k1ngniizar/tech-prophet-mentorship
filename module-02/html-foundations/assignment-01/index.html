Assignment 2.1 - My First HTML Document

What I have learnt so far:

The <!doctype html> is a declaration that tells the browser to use the correct html version.

The <html> element is the container for everything inside the html file.
The <head> element carries information and code about the webpage that the user shouldn't interact with directly.
The <body> element is the container for all the code that is displayed on the webpage.
The <title> element sets the title (that shows at the tab of the opened webpage.) of the html page.
An element is a combination of a particular opening tag, closing tag and the contents inbetween.
A tag is the first part of an element that indicates the start or close of that particular element.
An attribute is a part of an element that contains extra information about an element. It is usually written in the opening tag of an element.
Nesting is the act of putting element inside elements.
Void elements are elements that do not have a closing tag.
